# 第 2 周：Python 语法 I

目标：把"变量 / 输入输出 / 条件 / 循环 / 函数"这五样用熟，周末能独立写出**猜数字游戏**和**成绩统计脚本**。

每天 60–90 分钟，周末 2 小时。**每天结束前提交一次**。

## 七天安排

| 天 | 学什么（25 分钟） | 写什么（40 分钟） | 文件 |
|---|---|---|---|
| D1 | 变量、类型、f-string、`input` | 5 道小题 | `day01.py` |
| D2 | `if / elif / else`、比较、`and/or` | 猜数字 v1（答案写死） | `day02_guess_v1.py` |
| D3 | `while`、`random`、`break` | 猜数字 v2（提示大小、限 7 次） | `day03_guess_v2.py` |
| D4 | `for`、`range`、列表基础 | 九九表、求和、找最大 | `day04_loop.py` |
| D5 | `def`、参数、`return` | 把前两天的代码改成函数 | `day05_func.py` |
| D6 | 综合 | 成绩统计脚本 | `scores.py` |
| D7 | 复盘 | 写周记 + 提交 | `notes/第2周.md` |

## 本周验收（周日自查）

- [ ] 成绩统计能正确处理：0 分、100 分、全部不及格

## 卡住了怎么办

1. 先看报错最后一行（Python 的报错信息就在最后一行）
2. 把 `print()` 插进去，看变量到底是多少
3. 卡超过 20 分钟就跳过，记在周记里，第二天再看
