# 大一技术兼职 24 周计划（Python 自动化 + 数据处理）

> 前提：每周约 56 小时空闲，按 60%–70% 强度执行，实际投入约 38–40 小时。
> 主线：Python 自动化 / 数据处理；副线：内容输出 + 远程兼职/实习。
> 每周固定留 1 天完全不碰电脑；期中期末周整体降速 50%。

## 阶段 0：准备（第 1 周）

- 安装 Python 3.12（勾选 Add to PATH）、VS Code、Git；注册 GitHub。
- 建一个 `portfolio` 仓库，README 写上"我的 24 周计划"，以后所有代码都提交到这里。
- pip 换国内镜像：`pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`
- 三个方向各试水 3 小时：Python 自动化 / 前端建站 / 剪辑。**周五必须定下来，之后不改。**
- 建两个表：接单记账表、每周复盘表。

**验收**：GitHub 上有仓库；`python --version` 正常；读过并写过一个 Excel 文件。

**电脑说明**：这份计划不需要独显，4GB 内存的老机器也能跑。用 VS Code 而不是 PyCharm；不要装 Docker、不要本地跑大模型。

## 阶段 1：打地基（W2–W5）

### W2 · Python 语法 I
- 变量、类型、字符串、条件、循环、函数、输入输出。
- 每天 10 道小练习（自己出题：算平均数、判断素数、打印九九表）。
- 资源：廖雪峰 Python 教程 1–6 章（liaoxuefeng.com）。

**验收**：命令行猜数字游戏 + 一个成绩统计脚本（输入分数，输出平均/最高/及格率）。

### W3 · Python 语法 II
- 列表、字典、元组、集合；文件读写；`try/except`；模块与 `pip` 安装。
- 资源：官方 Tutorial 第 4–5 章；《Python 编程快速上手》第 1–6 章。

**验收**：读一个 CSV，统计并打印 Top10；文件不存在时给出友好提示而不是报错崩溃。

### W4 · 文件与 Excel 自动化
- `pathlib` / `os` 批量改文件名、按类型归档；`openpyxl` 读写单元格、改格式、加表头。
- 资源：《Python 编程快速上手》第 8–9 章、13 章；openpyxl 官方文档 Tutorial。

**验收**：
1. 把 200 个乱命名文件按日期批量重命名；
2. 给 10 个 Excel 统一加表头、调列宽、标红异常值。

### W5 · 网络请求与 pandas 入门
- HTTP 基础、`requests`、JSON 解析、headers；**合规**：先看 robots.txt，只取公开数据，限速。
- pandas：`read_csv` / `read_excel` / `groupby` / `to_excel`。
- 资源：requests 官方 Quickstart；pandas 官方《10 minutes to pandas》。

**验收**：调一个公开 API（天气、汇率、公开统计），存成 CSV，按类别汇总并导出 Excel。

## 阶段 2：做作品（W6–W9）

> 每个项目都要有：代码 + README + 30 秒屏幕录像 + 一段 100 字说明。这是接单的"样品"。

### W6–W7 · 项目 1：Excel 报表自动化工具
- 场景：把 100 个同结构表格合并 → 清洗 → 生成汇总表和图表。
- 技术：`pandas.concat` / `merge`、缺失值处理、`pivot_table`、openpyxl 图表。
- 进阶：用 `PyInstaller` 打包成 exe，让不懂电脑的人双击就能用。
- 资源：pandas 官方《Merge/Join/Concat》文档；PyInstaller 官方 Usage。

**验收**：一个 exe + 录屏 + README（写清输入输出）。

### W8 · 项目 2：公开数据采集与分析报告
- 选招聘、天气、电影票房这类公开数据；`requests` 不够再用 `Playwright`。
- 数据存 SQLite，pandas 分析，输出一份带图的 Markdown/PDF 报告。
- 资源：Playwright Python 官方文档；matplotlib 官方教程。

**验收**：报告 + 代码，报告里能看出 3 个结论。

### W9 · 项目 3 + 作品集
- 从身边痛点里选一个：课表整理、成绩分析、文件自动归档、社团报名表汇总。
- 整理作品集：GitHub `portfolio` 仓库首页列出 3 个项目，每个配截图/GIF。
- 资源：GitHub Pages 或直接一个 `README.md`。

**验收**：3 个项目全部上 GitHub，链接发给同学能看懂。

## 阶段 3：接第一单（W10–W14）

### W10 · 接单准备
- 闲鱼发布 3 条服务（Excel 合并、数据整理、脚本定制），标题带关键词。
- 做一张报价单：基础版 / 标准版 / 加急版。
- 记住三条规矩：**先收 30%–50% 定金；需求文字确认并截图；不接"先做后付"。**
- 报价公式：`预估工时 × 你的时薪 × 2`（多出来的是沟通、返工、需求变更）。

### W11–W12 · 首单
- 每天 30 分钟主动找需求：校园墙、班级群、闲鱼擦亮、本地商家群。
- 目标：1–2 单，哪怕只收 100 元，重点是拿到第一条好评。
- 交付流程：定金 → 中期发进度 → 交付 → 2 次内免费改 → 要好评。

**验收**：收到第一笔钱 + 一条文字好评。

### W13–W14 · 稳定 + 复盘
- 提价 20%–30%；把常见需求做成模板，交付时间砍半。
- 学 Git 基础（commit / branch / PR），以后接团队活要用。
- 资源：Learn Git Branching（learngitbranching.js.org）。

**验收**：累计 3 单，收入 500 元以上，记账表能算清自己的时薪。

## 阶段 4：进阶与求职（W15–W18）

### W15 · SQL
- SQLBolt 全部 18 课；装 SQLite 或 MySQL 练手。
- `SELECT / JOIN / GROUP BY / 子查询`，配合 pandas 使用。

**验收**：用 SQL 回答 5 个业务问题（如"每月销售额 Top3"）。

### W16 · 报表与可视化
- matplotlib / seaborn 出图；Excel 透视表 + 图表；学一点配色和排版。
- **验收**：一份 3 页的分析报告，外行也能看懂。

### W17 · 简历与投递
- 一页简历，项目占 70%，不写"精通"。
- GitHub 整理：置顶 3 个项目，README 写清"解决了什么问题"。
- 投 5 家远程兼职 / 实习（程序员客栈、码市、BOSS 直聘远程岗、学长内推）。

**验收**：简历 v1 + 5 条投递记录。

### W18 · 竞赛
- 报名蓝桥杯 / 中国大学生计算机设计大赛 / 数学建模。
- 刷 20 道基础算法题（LeetCode 简单题）。

**验收**：报名成功 + 20 题做完。

## 阶段 5：稳定与复利（W19–W24）

### W19–W20 · 叠加第二技能
- 二选一：FastAPI（做接口/小工具后端）或 HTML/CSS/JS（给项目做个展示页）。
- 做一个能在线访问的 demo（GitHub Pages 或免费云平台）。

### W21–W22 · 套餐化与复购
- 把服务打包成"月度报表代做""每周数据整理"，从一次性单子变长期收入。
- 回访老客户，问一句"最近还有没有要处理的表"。

**验收**：至少 1 个复购客户。

### W23–W24 · 复盘
- 算三件事：实际时薪、获客渠道转化率、返工率。
- 决定下学期主攻哪条：继续接单 / 冲实习 / 打竞赛。
- 写一份复盘文档，定下学期目标。
